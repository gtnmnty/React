# ⚛️ React

A personal learning repo for working through a self-imposed **React 19 + TypeScript mastery roadmap** — 52 projects, ordered from fundamentals to production-scale patterns.

## 🛠️ Stack

- **React 19**
- **TypeScript** — every project is typed (props, state, hooks) from the start, no exceptions.

## 📋 Format

No solutions or step-by-step guides here — each project entry defines *what* to build and *why*, not *how*. The struggle is intentional.

## 🗂️ Structure

The roadmap is organized into levels, roughly increasing in difficulty:

- **🧩 Level 1 — Fundamentals** (Projects 1–10): JSX, props, `useState`, controlled inputs, lists/keys, lifting state up.
- **⚡ Level 2 — Effects, Refs & Custom Hooks** (Projects 11–18): `useEffect`, `useRef`, custom hooks, context.
- **🔁 Level 3 — Reducers, Memoization & Routing** (Projects 19–30): `useReducer`, `useMemo`/`useCallback`, error boundaries, testing, routing.
- **🚀 Level 4 — React 19 Features** (Projects 31–40): `useTransition`, `useDeferredValue`, `useId`, Actions, `useActionState`, `useOptimistic`, Suspense, `use()`.
- **🏭 Level 5 — Production Patterns** (Projects 41–52): auth, CRUD, real-time UI, admin dashboards, accessibility, testing, performance, and a final capstone project.

Each project entry includes difficulty, estimated time, what to build, concepts practiced vs. newly introduced, suggested components/hooks, stretch goals, and what you should understand by the end.

## 🌿 Branches

Each level lives on its own branch, matching the roadmap's difficulty progression rather than a single linear `main` history. Check branches for work-in-progress and completed projects per level.

## 📖 Reference

- Full roadmap: [`react-19-roadmap.md`](./react-19-roadmap.md)
- Includes a concept coverage matrix (which projects touch which React APIs), a 7-day aggressive plan, a 14-day realistic plan, and a set of no-guide skill-assessment projects to attempt after finishing the roadmap.

## 🎯 Goal

Go from React fundamentals to being able to take a one-paragraph product idea and build it into a structured, production-shaped React 19 + TypeScript application — architecture, state, performance, accessibility, and tests included — without a project brief telling me how.
